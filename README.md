# Quantum-Game
this is a game for a quantum games, writed on Q#.
# WORK
game works like this:
* we create a qubit
* user write his variant
* the qubit goes to the Hadamar gate
  (\lvert 0\rangle \xrightarrow{H} \frac{\lvert 0\rangle + \lvert 1\rangle}{\sqrt{2}})
* the chanse:
  (P(0) = \frac{1}{2}, \qquad P(1) = \frac{1}{2})
* thats all!
